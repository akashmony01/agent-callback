# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep
discussion about the work. Harassment, insults and personal attacks aren't
welcome in issues, pull requests or anywhere else in the project.

To report a problem, contact the maintainer privately through
[GitHub](https://github.com/akashmony01). Reports are handled confidentially.
